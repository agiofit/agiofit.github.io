Essayez-les ensemble

Avec un Fit Profile et un Cut Profile dans le même dossier, l’implémentation de référence les compare sur votre ordinateur, et rien n’en sort :

python -m agiofit.cli fit-profile.json <garment>.cut-profile.json explained
