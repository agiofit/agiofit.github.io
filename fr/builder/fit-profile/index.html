Builder de Fit Profile

Prenez vos mesures au mètre ruban et obtenez un fichier qui les contient, pour que l’implémentation de référence les compare à un vêtement sur votre propre ordinateur.

Cette page ne garde rien : aucun brouillon, aucune copie, et rien n’est envoyé. Elle ne compare rien non plus : la comparaison se fait sur votre ordinateur. Dans cette version, elle n’ouvre pas un fichier créé auparavant.

Étape 1

Avant de mesurer

Tenez-vous debout sans vous crisper, en sous-vêtements légers ou en vêtements près du corps, sans chaussures. Un tour se prend tout autour, le mètre ruban à l’horizontale, ajusté au corps sans le serrer ; respirez normalement. Une longueur suit le corps. Les épaules et le bras demandent une deuxième personne ; le reste peut se prendre sans aide.

Remplissez ce que vous avez mesuré et laissez le reste vide : un manque est utile, une estimation non.

Une seule unité pour tout le fichier.

Cela vaut pour toutes les mesures du fichier.

Étape 4

Créez le fichier

Le fichier est vérifié avec le schéma publié avant que vous puissiez le télécharger.


      
      

        
Essayez-le avec un vêtement

        
Placez fit-profile.json dans un dossier avec un Cut Profile, et l’implémentation de référence les compare sur votre ordinateur :

        
python -m agiofit.cli fit-profile.json <garment>.cut-profile.json explained

        
Pas encore de Cut Profile ? Mesurez un vêtement avec le builder de Cut Profile, ou suivez le Quickstart pour installer l’implémentation de référence.
