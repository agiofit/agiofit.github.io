Agio Fit
il profilo di vestibilità che ti porti dietro

In sartoria l'agio è il margine progettato tra corpo e capo. Qui è uno standard aperto: tre documenti JSON, un algoritmo di riferimento e una regola — il profilo resta tuo, ai negozi esce solo la taglia.

01 · Il vocabolario

Tre documenti, un contratto

Tutto lo standard sta in tre schemi JSON. Il primo lo possiedi tu, il secondo lo pubblica chi vende, il terzo è l'unica cosa che viaggia tra i due. Apri gli esempi per vedere la forma reale dei dati.

Fit Profile

fit-profile.schema.json

Il tuo profilo: misure corporee (ognuna con source e observed_at obbligatori, tolerance fortemente raccomandata), preferenze di vestibilità e — il segnale più forte — lo storico di come i capi passati ti sono andati davvero.

{ "body": { "measurements": { "chest_circumference": { "value": 100, "unit": "cm", "source": "tape_measured", "observed_at": "2026-03-14T18:00:00Z", "tolerance": 1.0 }, "arm_length": { "value": 63, "unit": "cm", "source": "self_reported", // pesa meno "observed_at": "2026-03-14T18:00:00Z", "tolerance": 2.0 } } }, "history": [{ "garment_ref": { "brand": "Sartoria Esempio", "category": "shirts", "size_label": "41" }, "outcome": "kept", "zone_feedback": [ { "zone": "waist", "verdict": "roomy" } ], "kept_despite": ["waist"] // compromesso accettato }] }

Estratto semplificato: una voce di storico completa richiede anche occurred_at e source.

Cut Profile

cut-profile.schema.json

Come il capo è tagliato, non come il brand chiama la taglia: misure per taglia, agio previsto (intended_ease), elasticità. Il campo measurement_method è obbligatorio e senza default.

{ "brand": "Sartoria Esempio", "category": "shirts", "measurement_method": "flat_laid", // larghezze = ½ circonferenza "critical_zones": ["shoulders", "neck"], "sizes": [{ "size_label": "41", "finished_measurements": { "chest_width": { "value": 58, "unit": "cm" }, "shoulder_width": { "value": 46.5, "unit": "cm" }, "neck_circumference": { "value": 42, "unit": "cm" } } }], "intended_ease": { "chest": { "min": 12, "max": 20, "unit": "cm" } } }

Match Report

match-report.schema.json

La risposta. La sua forma è la parte normativa dello standard: confidenza esposta, spiegazione per zona, avvertenze esplicite. Quanto dettaglio contiene lo decide il livello di disclosure.

{ "recommended_size": "41", "confidence": 0.84, "disclosure_level": "explained", "alternatives": [ { "size_label": "42", "score": 0.95 }, ... ], "explanation": [{ "zone": "shoulders", "assessment": "as_cut" // niente numeri a questo livello: // vengono rimossi in serializzazione }] }

Dove passa il metro

Un nome entra nell’elenco standard solo se la specifica sa dire dove mettere il metro, con abbastanza precisione perché due persone che misurano lo stesso capo arrivino allo stesso numero. La specifica ne definisce sedici; una camicia ne usa cinque. Scegline uno per vederlo sul capo.

_width
misurata in piano e in larghezza: metà della circonferenza
_circumference
tutto il giro
_length
corre lungo il capo

Le definizioni sono tradotte: fa fede il testo inglese della specifica.

Queste definizioni non sono ancora provate. Sono state scritte a partire da come il settore pubblica le proprie misure e dalla coerenza interna, non da un tavolo con un metro sopra. Non sono state verificate con la pratica sartoriale né con la modellistica. Se due persone misurano lo stesso capo e ottengono numeri diversi, è questo il difetto che conta, e segnalarlo è il contributo più utile che questa versione possa ricevere.

02 · Provalo

Il matching, dal vivo

Qui sotto ci sono le risposte vere dell'implementazione di riferimento (python -m agiofit.cli), generate per i due profili d'esempio a ogni livello di disclosure. Scegli un profilo e un livello, e guarda cosa esce, e soprattutto cosa non esce. Il capo e i profili sono gli esempi reali del repository: la Classic Oxford di Sartoria Esempio (marchio fittizio), taglie 39–42.

Il simulatore richiede JavaScript.

03 · La privacy come design

Quattro livelli, una sottrazione da impedire

Il chiamante non decide quanto vede: lo decide il livello di disclosure, e i numeri vengono rimossi in serializzazione, non per buona volontà. C'è un test che lo verifica.

meno più esce dal vault

result_only

Taglia e confidenza. È tutto ciò che serve a un negozio per venderti una camicia.

explained

Aggiunge il giudizio per zona (buono, attenzione…) ma senza centimetri.

scoped

Aggiunge l'agio numerico sulle zone richieste. Per servizi di cui ti fidi di più.

full

Il profilo completo. Pensato per il tuo vault, non per terzi.

Perché «explained» nasconde i numeri: la perdita aritmetica

Le misure del capo sono pubbliche (stanno nel Cut Profile). Se la raccomandazione pubblicasse anche l'agio in centimetri, chiunque saprebbe fare:

116 cm di capo meno 16 cm di agio fanno un torace di 100 cm.

Una sottrazione ricostruisce la misura corporea. Per questo ai livelli bassi l'agio esiste nel calcolo ma non sopravvive alla serializzazione — provalo nel simulatore passando da scoped a explained.

04 · Sul tuo computer

Uso da terminale

L'implementazione di riferimento è Python puro, zero dipendenze. Dopo aver clonato github.com/agiofit/agiofit: 

# installazione e verifica (63 test, devono passare tutti)
$ cd agiofit/reference
$ pip install -e ".[dev]"
$ pytest
63 passed

# profilo maturo: senza livello vale quello della persona (result_only), qui si chiede explained
$ python -m agiofit.cli ../examples/profile-mature.json ../examples/cut-shirt.json explained
{ "recommended_size": "41", "confidence": 0.84, ... }

# cold start, solo il risultato
$ python -m agiofit.cli ../examples/profile-cold-start.json ../examples/cut-shirt.json result_only
{ "recommended_size": "41", "confidence": 0.25, ... }

05 · Da difendere in pubblico

Le decisioni che non sono una tabella taglie

a

kept_despite

L'unico campo che registra un compromesso accettato. Senza, il sistema impara che rifiuti le spalle strette; con, impara che accetti una vita larga pur di avere le spalle giuste. Nell'implementazione di riferimento un difetto già accettato pesa la metà quando si sceglie la taglia, e il giudizio sulla zona resta quello che è.

b

measurement_method obbligatorio, senza default

Le misure flat laid sono mezze circonferenze. È l'errore più diffuso del settore e produce raccomandazioni sbagliate di un fattore due, in silenzio. Qui, se non lo dichiari, il documento non valida.

c

offset_scale per zona

Un brand che «veste piccolo» veste piccolo nel torso. Applicare lo stesso spostamento in cm al collo — dove 1 cm è una taglia intera — trasforma una correzione utile in una risposta sbagliata. Lo storico si applica per zona: 1.0 sul torace, 0.2 sul collo. E la correzione va solo sulle zone che lo storico indica come sbagliate: un reso per spalle strette non allarga il torace.

d

Cold start con confidenza dichiarata

Zero misure corporee, un solo capo tenuto dello stesso brand: il sistema risponde comunque, con confidenza massima 0.40, rifiuta l'inferenza cross-brand e ti dice cosa aggiungere per migliorare. Lo storico vale più dei centimetri.
