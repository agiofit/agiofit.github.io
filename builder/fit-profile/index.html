Fit Profile builder

Take your measurements with a tape and get a file that holds them, for the reference implementation to compare with a garment on your own computer.

This page keeps nothing: no draft, no copy, and nothing is sent. It compares nothing either: the comparison runs on your computer. In this version it does not open a file you made before.

Step 1

Before you measure

Stand relaxed, in light underwear or close-fitting clothes, without shoes. A girth goes all the way round with the tape level, snug against the body and not pulling it in; breathe normally. A length follows the body. The shoulders and the arm need a second person; the rest can be taken alone.

Fill in what you measured, and leave the rest empty: a gap is useful, a guess is not.

One unit for the whole file.

It goes with every measurement in the file.

Try it with a garment

        
Put fit-profile.json in a folder with a Cut Profile, and the reference implementation compares them on your computer:

        
python -m agiofit.cli fit-profile.json <garment>.cut-profile.json explained

        
No Cut Profile yet? Measure a garment with the Cut Profile builder, or follow the Quickstart to install the reference implementation.
